# 📱 HobbyFinder – Smart Hobby Discovery App

A mobile application that helps users discover hobbies, activities, and communities near them based on their geographic location.

---

## 👩‍💻 Author
- Tassnim Ouerghemmi

---

## 🎯 Project Description
HobbyFinder is an academic mobile application designed to solve a common problem: finding interesting activities nearby.

Using geolocation and intelligent recommendation techniques, the app suggests hobbies such as sports, art, technology workshops, and social events based on user preferences.

---

## 🚀 Features
- 📍 Real-time geolocation
- 🗺️ Interactive map for nearby activities
- 🔍 Search and filtering (category, distance, level)
- 🤖 Smart recommendations (AI-based)
- 👥 Community and group interaction
- 📅 Event discovery and participation

---

## 🛠️ Tech Stack
- 📱 Mobile: Android (Java / Kotlin)
- 🌐 Backend: Node.js / Flask
- 🗄️ Database: Firebase / MongoDB
- 🗺️ Maps: Google Maps API
